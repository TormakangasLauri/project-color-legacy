# PROJECT COLOR / P.A.I.N-T

## WHAT IT'S ABOUT

Project Color (working title P.A.I.N-T) is a first-person beat-em-up about a mentally insane robot who has to maintain control over turf using paint. What originally started as practice work for the University of Jyväskylä has now become it's own standalone videogame project.


## WHO ARE MAKING IT

- [Törmäkangas Lauri](https://github.com/TormakangasLauri) - Head of art and animation
- [Seppänen Miko](https://github.com/mkeyos) - Head of programming
- [Luosma Vilho](https://github.com/TheFinguy) - Head of level design


## HOW ARE WE MAKING IT

For now we are using the Unity Engine, though this may change in development. All concept art and textures are drawn and painted in Adobe Photoshop and 3D modeling and animation is done in either Blender or Maya.
